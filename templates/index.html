HOW IT WORKS

Three steps, kept visible

01

Key generation

Two primes create a public key (n, e) and a private key (n, d).

02

Encryption

File blocks are padded and transformed with c = m^e mod n.

03

Decryption

The private key restores each block with m = c^d mod n.
